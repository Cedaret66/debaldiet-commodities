# Bridge Industrial Construction Website - Multi-Page Rebuild

A high-fidelity, comprehensive multi-page rebuild of [Bridge 510 Industrial Construction](https://bridge510.qodeinteractive.com/) built with React, React Router, Vite, Tailwind CSS, and modern web platform APIs.

## 🚀 Live Local Server
- Server URL: **http://localhost:3000**

## 🌐 Dedicated Multi-Page Architecture

Every navigation link has its own dedicated page matching the original site's exact content, imagery, and layout:

| Navigation Item | Dedicated Route | Description & Highlights |
| :--- | :--- | :--- |
| **Home** | `/` | Hero Revolution 3-slide carousel, 4 Feature banners, 2-column project management, Interactive portfolio & project modal, Client logos, Tabbed specialized services, Animated stats counters (34, 97, 15, 62), Testimonials, Team preview, Circular progress rings, Capability accordions, Latest news. |
| **About Us** | `/about-us` | Page banner, Corporate founding story (Est. 1998 in Brooklyn), 4 core pillars (Zero Incident Safety, ISO 9001/14001, Master Builders, Parametric Efficiency), Feature banners, 25-year excellence project management showcase, Company milestone roadmap (1998-2024), Leadership team, Testimonials, Client logos. |
| **Our Services** | `/our-services` | Page banner, Full Project Management Services overview, 6 detailed service modules with vector icons (*General Contracting*, *Project Planning*, *Refurbishment*, *Interior Design*, *Mining Construction*, *Chemical Engineering*), Heavy industrial hotline banner, Performance progress rings, Mutually exclusive capability accordions. |
| **Our Team** | `/our-team` | Page banner, Job-site culture showcase, Complete 8-member leadership & engineering team (*Philip Larson*, *Jean Scott*, *Miguel Anders*, *Evelyn Grant*, *Grace Hudson*, *David Meyer*, *Tiffany King*, *Christopher Wells*) with bios & social links, Careers callout, Numerical counters. |
| **Blog / Right Sidebar** | `/blog` | Page banner, 5 multi-format articles (*Green Buildings*, quote post *Responsive Building Envelopes*, *Zero Energy Homes*, link post *Passive Cooling Methods*, *Flooring Trends for 2019*), Active filter bar, Full right sidebar (Instant search, Author bio card, Category counts, Latest post thumbnails, Tag cloud). |
| **Contact Us** | `/contact-us` | Page banner, 3 International office hubs (*New York HQ*, *Amsterdam European Hub*, *Barcelona Mediterranean Branch*) with direct phones, addresses & emails, Working interactive consultation request form with validation, Central Brooklyn operations preview. |

## 🛠️ Commands

```bash
# Start Vite development server
npm run dev

# Build production bundle
npm run build

# Preview production bundle
npm run preview -- --port 3000
```
